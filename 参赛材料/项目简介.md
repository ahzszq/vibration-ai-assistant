# 振动 AI 实验助手

面向已有非线性振动模型的教学、学习和初步参数探索。项目将原始六状态动力学代码整理为网页，提供手动参数、自然语言和图片参数识别入口，降低反复改脚本和整理图表的操作成本。

AI 辅助解析需求、文档来源和图片中明确的参数，数值求解器负责真实仿真。参数校验后可比较多组实验，查看时域、功率谱、相轨线、庞加莱截面、有限时间李雅普诺夫指数及关联维数参考图，导出图像和实验记录。代理模型模块已删除。

程序可通过单文件网页或 Python 服务运行。已完成流程、导出和部分数值基准测试；真实模型识别准确率、设备单位标定和工程实证尚未完成。系统不提供自动混沌判定或工程安全结论。
