# 演示步骤与讲稿

建议5分钟，先演示无密钥流程，再根据真实模型配置展示AI。没有真实连接时应说明未调用模型，不把模拟接口结果当现场AI输出。

1. 0:00–0:40：说明已有振动脚本反复改参、整理结果的使用场景。展示顶部六模块与原代码默认值。
2. 0:40–1:25：参数设置运行快速试算，切换仿真结果，介绍时域/PSD/相轨线/截面。说明模型单位和有限窗口。
3. 1:25–2:10：切换动力学分析，展示有限时间指数和关联维数参考图，说明不能仅凭这些图判定混沌。
4. 2:10–3:10：AI助手配置真实模型，发送明确参数修改指令，或导入文本资料生成带来源计划。没有配置则只展示入口和核验步骤。
5. 3:10–4:00：图片调参上传清晰参数截图，真实视觉模型识别，核对原值/候选值/原文，勾选应用并运行。若未配置视觉模型，说明真实准确率尚待评测。
6. 4:00–4:40：导出与教程，选择PNG 600DPI或SVG，展示白底图和坐标设置。
7. 4:40–5:00：展示测试与数值报告，说明目前适用范围、待完成验证与推广方向。

不展示已删除的代理学习模块，不承诺未做的设备减振效果。
