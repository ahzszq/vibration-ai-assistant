振动 AI 实验助手 · 模块与图片调参完整版
版本日期：2026-10-22

1. 先把整个 ZIP 解压到普通文件夹，不要在压缩包里直接运行。
2. 双击“振动AI实验助手.html”，进入参数设置模块，点击“一键快速试算”。不需要 Python 或 AI 密钥。
3. 顶部按钮切换：参数设置、仿真结果、动力学分析、AI助手、图片调参、导出与教程。
4. 图片调参：先在 AI 助手填写支持图片输入的视觉模型和自己的密钥，再上传/拖入/粘贴截图，识别、核对、应用参数，最后运行仿真。
5. 需要 Python 服务版时，安装 Python 3.10+，双击“安装并启动.cmd”；之后使用“启动.cmd”。首次安装需要联网下载依赖。
6. 使用方法见“使用教程.md”和站内“使用教程”；参赛 PPT、视频位于“参赛材料”目录。
