# 导出与教程验证

本次分别使用本地 Chrome 和 Edge 实际运行快速仿真，点击页面下载按钮，保存并重新读取导出文件。测试脚本为 `tests/check_exports.cjs`。

- Chrome与Edge各完成34个实际PNG/SVG下载，共68个文件：五类图的自动标题与中文/符号标题、全部附加分析、2×4和8×2英寸画幅、24号字体。
- PNG解码成功；常规6×4英寸图尺寸为3600×2400；600 DPI元数据误差小于0.1；白底像素为不透明白色。
- SVG XML有效，白底矩形、矢量路径和内嵌标签均存在；无需外部字体资源。文字使用768 DPI图片，曲线保持矢量。这是混合SVG，不声称所有元素都是可编辑的矢量文字。
- 人工查看常规、中文、符号、大字体、竖幅、横幅样图及SVG渲染，未见本次样例的乱码、文字重叠或裁切。
- 不同图、所选状态、PSD模式和附加分析分别保存标题和范围，测试切换不串用。
- 超过2400万像素时明确阻止导出；无结果时不导出空图。
- 9步教程的翻页、定位高亮、Escape关闭、继续阅读，以及390×844手机尺寸检查通过。
- JS语法检查、原有聊天前端、动力学分析、聊天HTTP、文档计划、公开服务鉴权回归检查通过；AI接口回归使用模拟模型。

修复包括：SVG状态恢复覆盖裁剪函数、字体估计不准确、PNG下载链接未挂载且过早回收、共享标题可能串图。页面原始参数与动力学方程未更改。

边界：本报告验证给定环境和样例的文件显示与导出链路，无法保证所有第三方排版软件、任意字符和极端参数绝不出问题，也不替代物理模型、参数单位或稳态收敛验证。不要把显示正确等同于工程结论正确。

复现命令（需自行安装Playwright或配置其模块路径，并有Chrome/Edge）：

```
node tests/check_exports.cjs validation/export-check
```

可通过环境变量 `PLAYWRIGHT_MODULE` 指定模块位置，`CHROME_EXE` 指定浏览器可执行文件。
