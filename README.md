## 四、技术要点

- 动力学内核是原代码的六状态方程与四阶 Runge–Kutta（Fehlberg 的 √2 节点系数），定步长 `h = 2π/(Ω·NN)`，一个系数都没改
- 24 个参数（21 个物理量 + 3 个计算量），默认值即原代码默认值：20000 / 12000 / 256
- AI 层不产生数值、不执行代码，只输出结构化参数补丁，必须过四道闸门：参数白名单 → 数值合法性 → 物理范围 → 计算规模
- 密钥只存在页面内存，不写文件、不落盘、不写日志
- 后端只用 Python 标准库 `http.server`，无 Web 框架；安全响应头含 CSP、`X-Frame-Options: DENY`、`nosniff`
- 单文件版内嵌 PDF.js 3.11.174（Apache-2.0）解析文本 PDF

## 五、单文件版和 Python 版算的是同一组数

同一台机器、同一组参数，浏览器（V8）与 Python 各跑一次，逐字段比对：

| 比对项 | Python 服务版 | 单文件浏览器版 |
|---|---|---|
| RMS（快速试算 3840 点） | 1.3929455813320966 | 1.392945581332101 |
| 绝对峰值 | 1.6763246694 | 1.6763246694 |
| 主频 | 0.2148591732 | 0.2148591732 |
| 2000 步内逐步状态 | — | 逐位相同 |
| 默认全量 RMS（512 万步） | 1.38342579 | 1.38300984 |

最后一行的 0.03% 来自长时积分中 `Math.sin` 与 libm 在超大时间参数上的末位舍入差异，被干摩擦非线性放大，不是算法差异。换任何两套数学库都会这样。完整数据见 `参赛材料/本轮验证记录.md`。

## 七、边界（明确不做的事）

- 不做有限元、不做三维接触分析，不替代 ADAMS / Romax
- 不自动建立新方程
- **不判定混沌**：提供最大有限时间李雅普诺夫指数估计，不给分岔类型结论；庞加莱图只画点，不自动判周期或混沌
- **不标单位**：单位未标定，全部数据来自仿真，统计量是相对量，不能直接换算成工程值
- **不出结论**：不输出工程安全结论；有限时长结果不等于已收敛的稳态
- 不支持扫描版 PDF 的 OCR

AI 部分只验证了流程跑得通（本机模拟接口），**没有评测真实服务商模型的解析准确率**。这两件事不能混为一谈。

### 李雅普诺夫指数分析
附加分析的加速度项已替换为最大有限时间李雅普诺夫指数估计（Benettin 双轨迹重标定）。横轴为模型时间，纵轴为累计指数（模型时间单位⁻¹）。计算从末段首个状态开始，延续最多8个激励周期；两条轨迹使用相同外部激励，初始扰动1e-8，每约1/4周期重标定。六维状态使用原始模型坐标的欧氏范数、固定初始扰动方向。短窗口未保证方向收敛，结果不能视为已收敛最大渐近指数或混沌证明。请结合更长窗口、步长及扰动敏感性分析。PNG导出选择“附加分析图”，可设600 DPI。
