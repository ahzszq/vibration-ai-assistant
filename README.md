# 振动 AI 实验助手

2026-10-22 本地完整交付版。基于用户提供的六状态非线性动力学方程，支持手动调参、自然语言辅助、参数文档解析、图片识别调参、本地仿真及绘图导出。

## 立即使用

完整解压后双击 [振动AI实验助手.html](振动AI实验助手.html)。在“参数设置”点击“一键快速试算”，随后在顶部切换“仿真结果”或“动力学分析”。无需安装 Python；基础仿真无需 AI 密钥。详细步骤见 [使用教程](使用教程.md)。

## 六个功能模块

| 模块 | 功能 |
|---|---|
| 参数设置 | 六类参数按钮、原代码默认值、快速试算、参数 JSON 导入导出、三组阻尼对比 |
| 仿真结果 | 时域图、功率谱、相轨线、庞加莱截面、RMS/峰值/主频、六状态选择 |
| 动力学分析 | 有限时间李雅普诺夫指数、关联维数参考图、分窗 RMS、直方图、自相关、自定义状态投影 |
| AI 助手 | 自带密钥/模型、连续问答、调参、参数扫描、文本 PDF 等资料解析、带来源实验计划及结果问答 |
| 图片调参 | PNG/JPEG/WebP 上传/拖放/粘贴、视觉模型识别候选参数、勾选应用、撤销 |
| 导出与教程 | 所选图独立标题和范围、PNG 尺寸/DPI、SVG、CSV、站内教程 |

网页保持深色，PNG/SVG 采用白底。SVG 曲线和坐标线为矢量，文字嵌为高分辨率图层，不能按纯文字 SVG 编辑。6×4 英寸、600 DPI 对应 3600×2400 像素。

## Python 服务版

Python 3.10+。Windows 首次双击“安装并启动.cmd”，安装依赖并在本机 8765 端口启动；以后双击“启动.cmd”。其他系统可执行：

```sh
python -m pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:8765 。依赖安装需要网络。浏览器单文件版通过服务商接口直接调用 AI，受 CORS 和网络影响；服务版由本地后端调用。两种入口的仿真均由方程数值求解。

## AI 和图片调参

密钥只在页面内存中保留，不打进实验报告。连续对话可选择在浏览器保存文本，默认关闭。文档和图片只在点击相应 AI 操作时发送至所配置的服务商。图片调参需要支持图片输入的视觉模型，普通文字模型连接成功不代表有图片能力。

图片识别只提取现有参数的明确数值，应用前展示候选值与图片原文。用户应目视核对识别结果；不支持通过响应曲线反演参数。参见 [模块与图片调参说明](模块与图片调参说明.md)。

## 项目结构

- `振动AI实验助手.html`、`docs/index.html`：相同的自包含网页。
- `index.html`、`main.js`、`assistant.js`、`analysis.js`、`review.js`、`guide.js`、`modules.js`、`styles.css`：服务版界面源码。
- `app.py`、`physics.py`、`engine.py`、`ai_workflow.py`：HTTP 服务、原方程、数值求解及 AI 校验。
- `tests/`、`validation/`：流程和数值验证脚本、报告。
- `参赛材料/`：PPT v5、视频、当前简介/讲稿/提交清单及材料版本说明。
- `第三方许可证/`、`THIRD_PARTY_NOTICES.md`、`开源调研与复用.md`：来源和许可信息。

Docker 与公网部署文件已提供，但本次未实际构建 Docker 镜像或验证云账号部署。见 [部署说明](部署说明.md)。

## 验证和适用范围

已验证模块切换、真实仿真和关联维数曲线、图片多模态请求及应用/撤销、PNG/SVG 下载、桌面和窄屏布局。服务端验证图片格式和参数合法性。AI/视觉测试使用模拟接口，未评测真实服务商准确率；验证范围见 `validation/`。

默认参数保留原代码 20000/12000/256 配置。演示短窗口不代表稳态收敛。单位未标定，频率为模型时间的倒数；有限时间指数和关联维数参考斜率不构成混沌证明。正式论文需对实际参数复核步长、时长和数据窗口。
